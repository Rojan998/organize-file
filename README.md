# Organize File

A simple Windows desktop utility that automatically keeps your Downloads folder clean by sorting files into categorized folders based on file type.

This project watches the Downloads directory and moves files like PDFs, images, documents, archives, audio, video, and more into dedicated subfolders so you don’t have to organize them manually.

---

## Features

- Monitors the Windows Downloads folder
- Sorts files into category folders automatically
- Creates missing folders on the fly
- Ignores incomplete downloads like `.crdownload`, `.tmp`, and `.part`
- Avoids overwriting existing files by creating numbered duplicates
- Runs continuously until stopped with `Ctrl + C`
- Uses only Python standard library modules

---

## Supported File Categories

The script currently organizes files into the following folders:

- `pdf`
- `word`
- `images`
- `excel`
- `powerpoint`
- `text`
- `archives`
- `audio`
- `video`
- `other`

### Example mappings

- `.pdf` → `pdf`
- `.doc`, `.docx` → `word`
- `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp`, `.tiff` → `images`
- `.xls`, `.xlsx`, `.csv` → `excel`
- `.ppt`, `.pptx` → `powerpoint`
- `.txt`, `.md`, `.rtf` → `text`
- `.zip`, `.rar`, `.7z`, `.tar`, `.gz` → `archives`
- `.mp3`, `.wav`, `.m4a`, `.flac`, `.aac` → `audio`
- `.mp4`, `.mkv`, `.mov`, `.avi`, `.wmv` → `video`
- Unknown extensions → `other`

## Installation

1. Clone or download the project.
2. Open a terminal in the project folder.
3. Create a virtual environment:

```bash
python -m venv .venv
```

4. Activate the environment:

```bash
.venv\Scripts\activate
```

5. Run the application:

```bash
python main.py
```

### Optional: using `uv`

```bash
uv run python main.py
```

---

## How It Works

When the script starts, it:

1. Finds the current user’s `Downloads` folder
2. Scans all files in that directory
3. Ignores folders and incomplete downloads
4. Checks the file extension
5. Moves the file into the matching category folder
6. Repeats every 5 seconds

The program keeps running until you manually stop it.

## Duplicate Handling

If a file with the same name already exists in the destination folder, the script automatically renames it to avoid overwriting:

```text
file.pdf
file (1).pdf
file (2).pdf
```

---

## Stop the Script

To stop the watcher, press:

```bash
Ctrl + C
```

---

## Notes

- The script works best on Windows because it specifically targets the user’s Downloads folder.
- It only organizes files in the root of the Downloads folder, not nested subdirectories.
- It moves files rather than copying them.

---

## Why This Project Exists

A cluttered Downloads folder can become hard to manage quickly. This project helps automate a common task by sorting files into logical folders, making file management easier and more consistent.
